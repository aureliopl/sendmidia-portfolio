# Security

This repository is a portfolio edition, not a production service. Use disposable data and a separate environment. Never add credentials, private keys, contact exports, account sessions or database backups.

Security-sensitive changes should include a regression test. Run the repository's checks and a secret scanner before publishing. Dependency advisories can change after publication.

To report a concern privately, use the contact form at https://aureliopaz.com/en/. Do not include credentials or personal data in a public issue.
